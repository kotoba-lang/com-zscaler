# compat 系 actor は独立リポジトリ（kotoba-lang org）に移設されました

`20-actors/*-compat` の vendored コピー **844 件**を撤去しました（2026-07-16、ADR-2607171000 Phase 1）。

これらは `scaffold_wave*.py` で機械生成された統合 compat シムで、既に kotoba-lang org に
独立リポ `com-<base>` として移行・west 登録済みです（source of truth）。この monorepo 内の
vendored コピーは stale な重複だったため除去しました。

## 安全性

- 各 compat は west 登録済みの独立 kotoba-lang `com-<base>` リポを持つ（撤去前に検証）。
- `cell.cljc` を持たず fleet 非稼働。ns-require の runtime caller ゼロ（browser-WASM 実行）。
- hand-deepened な `salesforce-compat` / `stripe-compat` は個別レビューのため**保持**（本除去の対象外）。
- `70-tools` の Python コーポラ列挙ツール（`register_cleanroom_actors.py` 等）はこれらを
  `os.listdir` で参照するが、Python は prune 対象（cljs/nbb 再実装予定）であり CI 非配線のため
  本除去を妨げない。nbb 再実装時は manifest / 独立リポ列挙を source とする。
